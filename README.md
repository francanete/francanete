# Hey, I'm Fran 👋

I'm a **full-stack engineer in Manchester, UK**, building AI products, enterprise integrations, and workflow systems that actually ship.

I like software that earns its place: clear problem, small surface area, reliable execution, and measurable value for the people using it.

## What I build

At **ConnexAI**, I work on enterprise integrations for contact-centre platforms — the kind of software that connects the tools teams already depend on and removes friction from their day-to-day work.

Recent work includes:

- Dedicated CTI Chrome extension for third-party calling workflows
- Azure / Entra ID integration for user lifecycle automation
- Jira integration for side-by-side ticket management
- Microsoft Teams integration for internal collaboration workflows
- HubSpot and other platform connectors

I tend to work end to end: understand the customer problem, design the architecture, implement the system, and make sure it works in production.
